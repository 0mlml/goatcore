Quickstart

From download to first roundtrip

Fetch a prebuilt library (or build from source), verify its checksum, then walk the one obvious path — a producer seals, a consumer verifies, admits its slot, and opens, and the member rotates its leaf — in the language of your choice.

1. Fetch and verify

On-mesh, the SDK is served at get.<site>.<zone>/sdk/. The fastest path, when you just want to link a binding, is the prebuilt C ABI library for your platform:

To build the library yourself (an unlisted platform) or to run the test suites, take the source tarball instead:

Always verify

Every artifact ships a sibling .sha256, and the release also carries an aggregate SHA256SUMS. Verify before use. The core and the C ABI ship in lockstep from one tag — pull the library and the source from the same release.

2. Point your binding at the library

Each binding’s own README.md (shipped in the source tarball at grant-crypto/sdk/bindings/<lang>/) is the authoritative, CI-tested setup. The essentials:

3. The one obvious path

Every language walks the same flow — identity → acquire → seal → verify → admit → open → rotate — and each ships a runnable, CI-tested example so the code below can’t rot. The snippets are the shipped binding quickstarts; the expected output is from the runnable example that exercises the same flow.

Rust

The core crate directly — no C ABI. Parse the signed bundle off the fabric, acquire your producer key and seal under a Context (the required typed topic binding), admit/open as the consumer, then rotate your leaf.

plaintext recovers the sealed bytes (b"example snapshot"); seal refuses with Error::RotationRequired at the cumulative message-count cap (DEFAULT_SEAL_CAP = 2²⁴), and held DEKs zeroize on drop. The runnable proof is the core crate’s cargo test (roundtrip + conformance suites).

Where the inputs come from

The examples read their signed KeyBundle and key material from the committed cross-language conformance vectors — the same material every binding validates against — so they do not re-implement the key service. In production, bundles arrive off the fabric and the member scalar comes from the member’s enrollment credential. The vectors’ member identity has a slot in the base bundle, so it acts as both producer and consumer.
