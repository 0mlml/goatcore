Your SSH key

A host shell is a separate grant from your console login. Submitting a key here records it against {{.SSHKeyHandle}} and gives you no access. An admin reviews it, and only then is it installed. You will not be able to log in until that has happened.

Submit a public key

Never paste a file that begins -----BEGIN OPENSSH PRIVATE KEY-----. That is your private key; it is the secret itself. This form refuses it, but do not send it anywhere else either. If you have no key yet, run ssh-keygen -t ed25519 and submit the .pub file it writes.

SSH keys

Approving a key does not install it. The installer places approved keys on the hosts that person's role may reach, then marks them installed — so approved means decided, installed means they actually have a shell.
