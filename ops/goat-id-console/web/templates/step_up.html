What is "step-up" and why does this console ask for it?

Most of this console only needs you to be signed in. A handful of operations — deleting an identity, granting or revoking platform-admin, resetting someone's second factor, and a few others — can't be undone and affect everyone's access. For those, being signed in isn't enough: we ask you to prove it's still you, right now, with a second factor.

This is the control NIST SP 800-53 names IA-2. Every gated action is written to the audit log with whether a real second factor backed it, so "who did this, and how sure are we it was them" always has an answer.
